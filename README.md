# Chunkline Launcher bauen

Dieses Repository baut den Chunkline Launcher automatisch auf GitHub.

1. Neues Repository auf github.com anlegen und alle Dateien hochladen (auch den Ordner `.github`).
2. Oben auf **Actions** gehen, „Chunkline Launcher bauen“ wählen und **Run workflow** drücken.
3. Nach etwa 30 bis 60 Minuten unter dem fertigen Lauf bei **Artifacts** den Installer herunterladen.

Der Quellcode stammt von der Modrinth App (GPL-3.0). Name, Logo und Werbung von Modrinth werden entfernt.

Sprache: Beim ersten Start wird die Systemsprache des PCs übernommen (sonst Englisch). Alle Sprachen sind unter Einstellungen > Sprache umschaltbar.
